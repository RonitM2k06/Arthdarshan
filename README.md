# ARTHDARSHAN — Train before you face it.

An AI-assisted **financial decision-resilience simulator** (SANGYAN Investor Resilience Hackathon 2026, Track C). It trains *how* people decide under scams, pressure, FOMO and confusing information. It never recommends investments, predicts prices, or handles real money or credentials. All scenarios are **SIMULATED · NO REAL MONEY · FICTIONAL**.

**Status:** Phase 1 (architecture and repository structure). The application does not run yet. Nothing below is implemented unless the status says so.
