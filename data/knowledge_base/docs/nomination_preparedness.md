Nomination means naming a person you trust whom the institution should contact and pay if something happens to you. It helps the institution know whom to deal with. Rules about who ultimately inherits can differ from the nominee on record, so check each institution's own official guidance.

A simple family file is one page listing each account, which institution holds it, where the papers are kept, who the nominee is and which mobile number is registered. Share where the list is kept with a trusted person, but never your passwords, PINs or one-time codes. Keep contact details and nominees up to date through each institution's official channel, and review the list once a year.

Preparedness works only if it is done before it is needed. A genuine institution will never ask you to read out a one-time code or PIN.
